# 100-Days-Python-Challenge 🐍

Mastering Python by completing 100 unique projects covering **Automation**, **Game Development**, **Web Applications**, **Data Science**, and **Machine Learning**. Building proficiency in industry-standard libraries like **Selenium**, **Beautiful Soup**, **Flask**, **Pandas**, **NumPy**, **Scikit-Learn**, **Plotly**, and **Matplotlib**.

## 🛠️ Technologies & Libraries Used

### Core Python
- **Python 3.x** - Core language
- **datetime, random, time** - Built-in modules
- **collections, itertools** - Advanced data structures

### Web Frameworks & APIs
- **Flask** - Web framework for building web applications
- **Jinja2** - Template engine for Flask
- **SQLAlchemy** - ORM for database operations
- **Requests** - HTTP library for API calls

### Data Processing & Analysis
- **Pandas** - Data manipulation and analysis
- **NumPy** - Numerical computing
- **CSV module** - CSV file handling
- **JSON module** - JSON data handling

### Web Scraping & Automation
- **Beautiful Soup** - HTML/XML parsing
- **Selenium** - Browser automation
- **Scrapy** - Web scraping framework (if used)

### GUI & Graphics
- **Tkinter** - Desktop GUI framework
- **Turtle Graphics** - Drawing and graphics
- **Matplotlib** - Data visualization
- **Plotly** - Interactive visualizations

### Machine Learning & Advanced
- **Scikit-Learn** - Machine learning algorithms
- **Pandas** - Data manipulation

### APIs Integrated

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/ajaykh053-lgtm/100-Days-Python-Challenege.git
   cd 100-Days-Python-Challenege
   ```

2. **Install required packages**
   ```bash
   pip install -r requirements.txt
   ```

3. **Explore individual day folders** to see project code and documentation

4. **Follow along with each day's challenge** and build your skills progressively
